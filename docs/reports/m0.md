## Incident

One `next build` requested a remote Wrangler preview session against the logged-in customer Cloudflare account (request rejected with error 10021; nothing created or deployed). Cause: the template's `remoteBindings: isProduction` plus `remote: true` in `wrangler.jsonc`. Fixed by E-006; every later build logged 0 Cloudflare API mentions.
