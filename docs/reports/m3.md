## Completion rule

A `DONE` claim requires path evidence for every acceptance-owned output. Leaf tests, a passing subset of gates or a report status do not prove that routes, persistence, user interfaces, Worker entry points and other required outputs exist. The completion-evidence eval keeps this rule executable.

Every aggregate gate failure is recorded before remediation. The record names each failed gate and preserves its output. Historical worker reports and prior attempt telemetry are not rewritten after the fix. The aggregate-gate eval keeps this ordering rule executable.
