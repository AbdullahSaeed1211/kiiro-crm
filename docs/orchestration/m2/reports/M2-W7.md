# Report: M2-W7

Implemented and review-hardened the CRM directory vertical for organizations and contacts. Both record types now have searchable, paginated list pages, create flows, guarded edit flows, relation-aware record pages, activity display, owner/details metadata, and contact copy affordances. Review fixes cover server-derived ownership, parent-authorized staff activity reads, complete organization options, resilient form errors, reliable relation empty states, and protocol-safe website links.

The first append-only harness attempt (`M2-W7-a1`) captured a formatter failure that was fixed before the clean attempts. It is retained as evidence rather than overwritten. A post-review full-gate failure exposed two directory import cycles: `data.ts` imported `utils.ts` and `helpers.ts`, while both modules imported shared types from `data.ts`. The root cause was contract drift in the module dependency shape, confirmed as `CONTRACT_DRIFT` in attempt 7.

The countermeasure is the focused `types.ts` extraction. `helpers.ts` and `utils.ts` now depend on the shared type owner, while `data.ts` retains compatibility re-exports. The targeted directory dependency-cruiser check, focused tests, and attempt 7 all pass. The repository-wide dependency-cruiser command still has the two unrelated seed-script cycles listed in the acceptance evidence above. This repair did not weaken dependency rules or change those out-of-scope files.

Remediation commit: `06290ab7f3debc0aee408f5fbf498dfa038d7883`.

Seeded browser acceptance then reported a Base UI warning on both directory list pages and the shared directory-owned empty-state and record views. The warning occurred because `Button` received an anchor through `render` while `nativeButton` remained true. This was classified as `ACCESS_SCOPE` and `GATE_FAILURE` in attempt 9.

The countermeasure declares `nativeButton={false}` on all five directory `Button` anchor renders without changing navigation or styling. The focused source-contract regression checks all five sites, and focused tests, web typecheck, lint, build, formatting, scope, and harness attempt 9 pass. No directory-specific Playwright console-warning test exists in the repository.
