2. `pnpm dev` writes `apps/web/AGENTS.md`, `apps/web/CLAUDE.md` and a changed `next-env.d.ts`. These were reverted here, but every worker running dev will hit them.
3. Links are plain anchors, because `@ops/ui` cannot import `next/link`.
