# Brief: M0-W2 — CI workflow

- **Milestone:** M0 · **Attempt:** 1 · **Branch:** `wp/M0-W2` from `m0-bootstrap`
- **Objective:** Create `.github/workflows/ci.yml` that runs on pull requests and pushes to `main`: checkout, setup Node from `.nvmrc`, enable pnpm via the `packageManager` field (pnpm/action-setup without a version input so it reads `packageManager`), cache the pnpm store, `pnpm install --frozen-lockfile`, then `pnpm verify`. Upload Playwright traces and coverage as artifacts on failure only.
- **Spec references:** §6.6, §19.4 (`ci.yml`), §0.11 (no secrets in worker-run jobs).
- **Write scope:** `.github/workflows/ci.yml`
- **Inputs:** root `package.json` scripts, `.nvmrc`, `pnpm-workspace.yaml`.
- **Acceptance:** the YAML parses (`node -e` with a YAML-free check: `npx --yes yaml-lint` is not allowed; instead validate by running `ruby -ryaml -e "YAML.load_file('.github/workflows/ci.yml')"` or Python `yaml.safe_load`), uses only pinned major versions of official actions (`actions/checkout@v4`, `actions/setup-node@v4`, `pnpm/action-setup@v4`, `actions/upload-artifact@v4`), references no secrets, and sets `permissions: contents: read`.
- **Boundaries:** no other files; no deploy steps (deploy.yml is lead-owned).
- **Report:** `docs/orchestration/m0/reports/M0-W2.md` with front matter per `harness/schemas/report.schema.json`.
