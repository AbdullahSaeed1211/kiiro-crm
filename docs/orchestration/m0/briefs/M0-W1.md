# Brief: M0-W1 — Repository check scripts

- **Milestone:** M0 · **Attempt:** 1 · **Branch:** `wp/M0-W1` from `m0-bootstrap`
- **Objective:** Implement `scripts/check-brand.ts`, `check-vocab.ts`, `check-disables.ts`, `check-docs.ts`, `check-size.ts` and `check-scope.ts`, each ≤ 80 lines (check-scope ≤ 150), with unit tests and planted fixtures that make each check fail.
- **Spec references:** §3 (constraints 2, 3, 5), §6.5, §6.2 (gated rule names), §7.3, §0.7 (critical paths), §0.8 step 5.
- **Behavior:**
  - `check:brand`: case-insensitive search for `mirch`, `frappe`, `twenty`, `plane`, `huly` and names listed in `tenants/*.jsonc` `displayName` under `apps/**` and `packages/**` (excluding `node_modules`, `.next`, `.open-next`, `apps/web/cloudflare-env.d.ts`); optional `--path <dir>` to scan build output. Exit 1 with `file:line token` lines.
  - `check:vocab`: forbid `lead|deal|contact|organization|project|task|matter|inspection|patient|booking` as whole words in `packages/kernel/**` and `packages/platform/**` source (not tests); exit 1 with locations.
  - `check:disables`: fail on `eslint-disable` comments that name any gated rule from `tooling/eslint/rules.js`.
  - `check:docs`: every workspace package has `README.md` with `## Purpose` and `## Public API`; `packages/modules/*` also `## Ports` and `## Invariants`; exported functions from `packages/{kernel,platform}/src` and `packages/modules/*/src` have a TSDoc block.
  - `check:size`: read the size of `apps/web/.open-next/worker.js` plus `.open-next/server-functions/default/handler.mjs` if present, write `docs/reports/size.json` only when `--write` is passed (lead only), and fail on > 20% growth versus the committed value unless `--allow-growth` is passed; no build output → exit 0 with a notice.
  - `check:scope <WP-ID>`: read the WP row from `docs/orchestration/m<N>/plan.md` (write scope column, `;`-separated, trailing `/` = directory), diff `git diff --name-only <milestone-branch>...HEAD` (branch passed via `--base`, default the current upstream), fail on any §0.7 critical path, print out-of-scope paths as `FLAG`, always allow `harness/metrics/attempts/<WP-ID>-a*.json` and `docs/orchestration/m<N>/reports/<WP-ID>.md`.
- **Write scope:** `scripts/check-brand.ts`; `scripts/check-vocab.ts`; `scripts/check-disables.ts`; `scripts/check-docs.ts`; `scripts/check-size.ts`; `scripts/check-scope.ts`; `scripts/lib/`; `scripts/test/checks/`; `scripts/fixtures/checks/`
- **Inputs:** root `package.json` scripts, `tooling/eslint/rules.js`, `docs/orchestration/m0/plan.md` table format.
- **Acceptance:** `pnpm vitest run scripts/test/checks` passes; each planted fixture makes its check exit 1; `pnpm check:brand`, `check:vocab`, `check:disables`, `check:docs` exit 0 on the repository.
- **Boundaries:** no changes to §0.7 critical paths, dependencies or lockfile; Node built-ins only (no new packages); TypeScript strict per `tooling/tsconfig/base.json`; functions within §6.2 limits.
- **Report:** `docs/orchestration/m0/reports/M0-W1.md` with front matter per `harness/schemas/report.schema.json`.
