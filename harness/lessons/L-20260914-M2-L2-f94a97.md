M2 integration exposed stale cross-layer contracts and circular imports in the CRM graph. Keep shared contracts in leaf modules and run the dependency graph gate before integration.

## Symptom

M2 integration exposed stale test or seed contracts and circular imports in the directory and seed graphs. Source attempts: M2-L2-a1-lead, M2-W5-a2-lead, M2-W5-a3, M2-W5-a4, M2-W7-a7, M2-W7-a8, M2-W8-a2, M2-W8-a3.

## Cause

The shared contract owner was not kept at a dependency leaf. Seed and directory modules re-exported or imported through aggregators, creating cycles, while integration fixtures retained assumptions from an earlier contract.

## Countermeasure

The dependency-cruiser configuration remains enforced by `pnpm depcruise`. New shared types belong in a leaf contract module, and aggregators may re-export them only after the graph check passes. The eval reproduces a cycle and verifies the acyclic graph.
