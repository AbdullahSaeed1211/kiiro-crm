# CONTRACT_DRIFT in settings actions

The settings action graph must keep shared result types below the barrel that exports member actions.

## Symptom

`pnpm depcruise` reports a cycle between `settings/index.ts` and `settings/members.ts`.

## Cause

`members.ts` imported `ActionResult` through `index.ts`, while `index.ts` re-exported runtime actions from `members.ts`.

## Countermeasure

Shared action types live in a leaf module. Member actions import those types from the leaf, and the public barrel may re-export them.

## Eval

`harness/evals/L-20260923-M3-L1-e07ae8/eval.json` reproduces the action barrel cycle and verifies the leaf-type graph.
